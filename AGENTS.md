# Presence development guidance

Before changing mobile UI, read [Presence design foundation](docs/design/EVENTS_CIRCLE_PRESENCE.md) and [UI/UX review standard](docs/UI_UX_REVIEW_STANDARD.md). Reuse mobile/design/tokens.ts and existing shared components. Preserve authentication actions, API contracts and local-state navigation. Distinguish browser checks from native device testing. Use the repository's pinned pnpm and Expo-compatible dependencies.
